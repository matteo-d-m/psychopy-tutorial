## 1.0. Prerequisite Jargon
In Python jargon, a file that contains code to carry out specific tasks is called _module_. For example, one could take all the code that could ever be needed to draw rectangles and save it into a Python file called `rectangles.py`: that would be a module &mdash; specifically, a rectangles-drawing module.

Collections of modules that carry out related tasks are called _packages_. For example, one might take a number of geometry-drawing modules (one for each geometric figure of interest) and save them into a folder called `geometry/`: that would be a package. 

Finally, collections of packages that can interact to serve a higher purpose are called _libraries_. For example, one might take the `geometry/` package and put it in the same directory as other packages: a stimulus timing package, a response collection package. etc. That would be a library. 

PsychoPy is a collection of packages, so it is a library. It contains a number of different packages, each serving a specific function through multiple modules. For the purpose of an experiment where subjects watch stimuli on a screen, the package of interest is called `visual`.

```bash
psychopy/           # a library containing multiple packages
├── package1
├── package2
├── package3
├── ...
└── visual          # a package for drawing visual stimuli
    ├── file1.py    # a number of files serving specific, interrelated functions
    ├── file2.py
    ├── file3.py
    ├── ...
    └── fileN.py
```

## 1.2. The `visual` package
The `visual` package contains Python code to draw a variety of geometric stimuli, display images, draw complex patterns like visual gratings, and anything else that might be relevant for screen-based experiments.

Stimuli are drawn on a specific _window_, which you can think of as one of the usual windows on your computer (e.g., a browser window or a Microsoft Word window). This window can be as large as the screen, or smaller. Opening a window is as simple as running the following code:

```python
from psychopy import visual

window = visual.Window(color="black")
``` 

This code imports the `visual` package (that is, it makes it accessible to the Python code you will be running), then it instantiates a `Window` object and it assigns it to a variable called `window`. This `Window` object has an attribute called `color`, which is initialised to `black`. Basically, this means that the code creates a virtual black canvas to draw stimuli on &mdash; a canvas to which we can refer with the name `window`.
 
Like in the physical world, a canvas cannot stand without some hardware to support it. That hardware will be your monitor (or _screen_).

Different monitors have different physical properties. The most basic are height, width, and pixel resolution (that is, how many pixels compose the image on every dimension). Moreover, monitors can be used in different ways. For example, different subjects might sit at different distances from the screen &mdash; which is vital to consider if your stimuli are in [degrees of visual angle (°VA)](https://en.wikipedia.org/wiki/Visual_angle).

The following code specifies the physical properties of a monitor and how you use it, then it uses them to specify the properties of a `monitor` object. The `window` object will take these properties into account to draw images that have an optimal fit to the screen. 

```python
from psychopy import monitors

MY_SCREEN_NAME = "screen"
MY_PIXEL_WIDTH = 1366
MY_PIXEL_HEIGHT = 768
MY_SCREEN_WIDTH = 47                # cm
SUBJECT_DISTANCE_FROM_SCREEN = 65   # cm

monitor = monitors.Monitor(name=MY_SCREEN_NAME)
monitor.setSizePix([MY_PIXEL_WIDTH, MY_PIXEL_HEIGHT])
monitor.setWidth(MY_SCREEN_WIDTH)
monitor.setDistance(SUBJECT_DISTANCE_FROM_SCREEN)                    
monitor.saveMon()                    
```

Once you have set monitor properties and initialised a window, you can draw a stimulus on it. For example, you can draw a white rectangle on a black background, as done by the code below:

```python
window = visual.Window(color="black")
stimulus = visual.rect.Rect(win=window, fillColor="white")
```
