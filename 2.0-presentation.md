# Chapter 2: Presenting Stimuli With the Right Timing 

Timing can be very important. At a minimum, you need to make sure that:
- Stimuli appear when you want them to
- Stimuli remain on for as long as you want them to
- Stimuli are synchronised to the physiological events of interest
    - For example: if you are doing EEG, your stimuli will be probably interleaved by milliseconds (instead of seconds). But if you are doing fMRI, they will be interleaved by seconds

Each stimulus must have a given display time (measured in seconds). For example:

```python
display_time = 0.1 # one tenth of a second = 100 ms
```

This display time must be transformed into a number of frames. A frame is one of many still images that compose a complete moving picture ([Wikipedia](https://en.wikipedia.org/wiki/Film_frame)). Importantly, different screens can display different numbers of frames in one second. The number of frames displayed per second is the frame (or _refresh_)rate of your screen ([Wikipedia](https://en.wikipedia.org/wiki/Frame_rate)) and is measured in hertz (Hz).

```{aside}
_Frame rate_ and _refresh rate_ are often used interchangeably, but _refresh rate_ is better when talking about screens (and _frame rate_ when talking about GPUs)
```

To transform a display time into a number of frames, you must multiply it by your screen's refresh rate:

```python
REFRESH_RATE = 60 # Hz
frames_per_stimulus = display_time*REFRESH_RATE
```
The number of frames per stimulus will serve as a range to iterate over. This means that you basically tell your machine: "Display this item for as many frames as you can fit in a given time interval":

```python
for frame in range(frames_per_stimulus):
    # display item
```

But, how do you actually _display_ an item? `Window` objects have a method called `flip()`. Every time this method is called, a window object transitions from one frame to the following. Importantly, each frame is treated as a separate unit &mdash; that is, stimuli displayed on one frame are not automatically displayed on the next. As drawing stimuli takes time, making a full draw from scratch on every frame would take up precious computation time, possibly compromising the temporal accuracy of behavioural measurements. Therefore, every visual stimulus that must be drawn has `setAutoDraw()` method, which allows to draw a stimulus on every frame without giving explicit frame-by-frame instructions. `setAutoDraw()` is called once before starting to iterate over frames, setting a stimulus to an auto-drawing mode that will apply to every frame. 

```{margin}
Technically, all `ShapeStim` objects
```

```python
window = visual.Window(color="black")
stimulus = visual.rect.Rect(win=window, fillColor="white")

stimulus.setAutoDraw(True)
for frame in range(frames_per_stimulus):
    window.flip()
```
