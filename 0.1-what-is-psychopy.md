# Chapter 0 &mdash; What is PsychoPy?

PsychoPy [Peirce et al., 2019](https://doi.org/10.3758/s13428-018-01193-y) is a Python library to program psychological experiments. Like many Python libraries, PsychoPy is free, open source, and the result of a large-scale collaborative effort.

In practice, PsychoPy is a folder containing code to generate visual stimuli and auditory stimuli, time events, interact with external hardware (like keyboards, response boxes, cameras, eye tracking devices, or neuroimaging systems), and more.

When you install PsychoPy from the official website, you are prompted to install the PsychoPy Standalone Version (SPV) &mdash; which includes  a code editor called Coder, a graphical user interface (GUI) called Builder (where you can build experiments by pointing-and-clicking), and a dedicated terminal/process manager called Runner.

Most of the official PsychoPy tutorials focus on the Builder, which empowers everyone with the ability to program experiments regardless of their skills. Therefore, people that have some programming skills and want to write their own experiment code<sup>1</sup> might struggle to find online resources. This website focuses on programming a visual neuroscience experiment using only code, without ever referring to the Builder.
