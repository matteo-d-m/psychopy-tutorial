# 4.1. Encoding Buttonpresses

After presenting a stimulus with given timing (possibly, for multiple conditions), it is necessary to collect responses from subjects. These responses will be collected by peripheral devices like a keyboard, a mouse, or a response box. In PsychoPy, code to handle input from peripheral devices is contained in the `event` module. Of particular interest for most experiments, `event` contains a `getKeys()` function that continuously checks for keypresses and returns a list of the presses that it finds. For example, if you press the `left` key `getKeys()` will detect it and return the following list: `["left"]`.You can specify the keys that you are interested in with the `keyList` argument. If you do so, `getKeys()` will check exclusively for the keys contained in `keyList`. For example, the following code contains a call to `getKeys()` that is only sensitive to the `left` and `right` keys:

```python
from psychopy import event

pressed_key = event.getKeys(keyList=["left","right"]) 
```

Once you have stored the keypress in a variable, you can use it to score responses:

```python
response = pressed_key[0]   # access the pressed key
if response == "left":
    correct = 1             # means "yes"
elif response == "right":
    correct = 0             # means "no"
```

## 4.2. Measuring Response Timing

Often, the timing of a response is as important as its identity. This is the case when your dependent variable is a participant's _reaction time_ &mdash; that is, the length of the time interval between stimulus onset and the subject's response.

PsychoPy provides a wealth of tools to measure timing. These tools are scattered across the `core` and `clock` modules. Based on the maintenance status of the two modules, it is reasonable to hypothesize that all timing tools will migrate to `clock` in the future. However, this is just a hypothesis: at the current state of things, you must deal with the duplication and visit the documentation of both modules to choose the tool that suits your needs<sup>1</sup>  

```{margin}
<sup>1</sup> The documentation for `core` can be found [here](https://www.psychopy.org/api/core.html), while the documentation for `clock` can be found here [here](https://www.psychopy.org/api/clock.html)
```

Conceptually, clocks are used as per the pseudocode below: after initialising a clock object (in this case, using the `Clock` class from the `core` module), you take the time of desired events and you reset as needed

```python
from psychopy import core

response_clock = core.Clock()
for trial in my_trials:
    # present your stimuli 
    if response:
        reaction_time = response_clock.getTime()
        response_clock.reset
```

Depending on your goals, resetting the clock after taking the time can be **VERY** important. In fact, forgetting to do it entails taking incremental times, which is not what you if you need to take the time with respect to an event<sup>2</sup>.  

```{margin}
<sup>2</sup> As is the case for reaction times, which are calculated with respect to stimulus onset
```

In detail, this is what happens if you try to take reaction times without resetting your clock:

- First reaction time: `clock.getTime()` - $t_{init}$ &mdash; where $t_{init}$ is the time when you initialised your clock (i.e., when `response_clock = core.Clock()` was executed)
- Second reaction time: `clock_getTime()` + first reaction time
- Third reaction time: `clock_getTime()` + second reaction time
- etc...

And this is what should happend: 
- Any reaction time: `clock.getTime()` - $t_{stimulus \ onset}$

The code below demonstrates drawing a yellow rectangular stimulus on a black window, then presenting it for a number of trials (defined as per [Chapter 3](3.0-conditions.md)). Within each trial, the stimulus is drawn on a number of frames (calculated as per [Chapter 2](2.0-presentation.md)) and responses are taken as described above:

```python
from psychopy import visual, core, event

window = visual.Window(color="black")
stimulus = visual.rect.Rect(win=window,
                            fillColor="yellow")

response_clock = core.Clock()

for trial in my_trials:                     
    stimulus.setAutoDraw(True)
    window.callOnFlip(response_clock.reset) # analogous to setAutoDraw
```
